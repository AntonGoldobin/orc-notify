# Sound presets

Four short distinctive beeps, each ~0.25s, generated by `generate.py` (stdlib only — `wave`, `math`, `struct`).
Regenerate with:

```
python3 generate.py
```

Files:
- `chime.wav`     — 660 Hz sine, linear attack/decay
- `bell.wav`      — 880 Hz sine, exponential decay
- `pop.wav`       — 440 Hz triangle, fast attack/decay
- `alert.wav`     — 1040 Hz square, short blip with quick decay
